? How to connect your Google Sheet in 2 Minutes
  1. Create a new spreadsheet at sheets.new.
  2. In the menu, click Extensions > Apps Script.
  3. Paste the code from google_apps_script.js (or click "Copy Apps Script Code" above) and click Save.
  4. Click Deploy > New deployment, choose Web app, set Who has access to Anyone, click Deploy, and paste the resulting Web app URL into the box above!
